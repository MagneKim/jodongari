# PROJECT.md

## 목적

`jodongari`는 소수의 동호회 멤버가 사용하는 비공개 탐조 커뮤니티 웹 앱이다.
전문 조류 관찰 DB가 아니라, 아래를 결합한 앱을 목표로 한다.

- 탐조 기록
- 개인 새 도감
- 사진 공유 / 커뮤니티 (댓글, 반응)
- 가벼운 게임화 (경험치, 레벨, 새 맞히기)
- 추후 간단한 채팅

## 핵심 컨셉

> 우리끼리 기록하고, 공유하고, 새를 모으고, 놀 수 있는 탐조 커뮤니티

## UX 원칙

- 모바일 사용성 최우선, 기록 입력 단계 최소화
- 사진 중심 UI, 복잡한 form 지양
- 친근함 / 탐조 / 자연 / 작은 커뮤니티 분위기 (업무용 SaaS 느낌 지양, 과도하게 유아적인 디자인도 지양)

## V1 제외 기능

AI 조류 판별, 복잡한 실시간 채팅, push notification, 추천/랭킹 알고리즘,
외부 조류 API, cron, Supabase Edge Function, 고급 관리자 시스템, 고급 지도 기능.
